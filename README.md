# Personal Portfolio

# Overview
Designed a modern and responsive personal portfolio using Figma to showcase projects, skills, and experience. The design focuses on clean UI, intuitive navigation, and visual consistency.

## Objectives
- Create a visually appealing portfolio layout
- Ensure smooth and intuitive user navigation
- Maintain consistency in typography, colors, and spacing

## Tools Used
- Figma

## Features
- Clean and minimal UI design
- Responsive layout concept
- Structured sections: About Me, Projects, Skills, Contact
- Consistent design system (colors, typography)
